# 計画相談データ転記・反映アプリ

項目名と書き方（記入例）をAIが読み取り、計画相談のExcelの「入力内容」欄へ自動で反映するアプリです。
ホーム画面に追加すると、スマホ・タブレット・パソコンで普通のアプリのように起動できます（PWA）。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体 |
| `manifest.webmanifest` | アプリ名・アイコン・テーマ色（ホーム画面に追加するための設定） |
| `sw.js` | オフライン起動用のキャッシュ（Service Worker） |
| `icons/` | アプリアイコン |

## 公開方法（GitHub Pages）

1. GitHub のリポジトリ画面で「Settings」→「Pages」を開く。
2. 「Source」で「Deploy from a branch」を選び、ブランチ（例：`main`）とフォルダ `/ (root)` を選んで保存する。
3. 数分後、`https://<ユーザー名>.github.io/8303/keikaku-soudan/` で開けるようになります。

※アプリとしてインストールするには `https://` で公開されている必要があります（ファイルを直接ダブルクリックで開いた場合も使えますが、インストールとオフライン起動はできません）。

## アプリとしてインストールする

- **Android / パソコンの Chrome・Edge**：画面上部の「📲 アプリをインストール」ボタン、またはアドレスバーのインストールアイコンを押す。
- **iPhone / iPad（Safari）**：共有ボタン →「ホーム画面に追加」。

## 最初に1回だけ：AI設定

AI判定（ステップ3）には Google の Gemini APIキーが必要です。

1. [Google AI Studio](https://aistudio.google.com/apikey) で APIキーを発行する。
2. アプリ右上の「⚙ AI設定」を開き、APIキーを貼り付けて「保存」。

- APIキーはその端末のブラウザ内にだけ保存されます。共用パソコンでは使用後に「削除」してください。
- 使用モデル（初期値 `gemini-3-flash-preview`）は同じ画面で変更できます。
- 利用者の個人情報は AI 判定のときに Google の Gemini API へ送信されます。事業所の個人情報の取り扱いルールに沿ってご利用ください。

## データの保存について

- 作業中のデータ・基本データに固定したExcelは、その端末のブラウザ（IndexedDB）に自動保存されます。
- ブラウザの「閲覧データを削除」をすると消えるため、必要なExcelは「Excel出力」で保存してください。
