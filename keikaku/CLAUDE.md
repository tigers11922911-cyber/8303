# 計画相談 様式アプリ

相談支援従事者初任者研修の提出課題（①〜⑨）と送付票・同意書・実習報告書を、1回の入力から作るアプリ。
Googleドライブ「【100】アプリ › 計画相談 › 入力ホーム付様式」の **入力フォーム付きPDF** に、入力した内容を書き込む。
作りは「税金計算（zeikin-simulator）」と同じ：HTML1枚＋pdf-lib＋日本語フォント、claude.ai のアーティファクトとして公開するとドライブ連携・クラウド保存が動く。

## ファイル
- `index.html` … 画面（入力タブ・様式の一覧・プレビュー・ドライブ保存）。アーティファクトとして公開するので `<html>` `<head>` は書かない
- `forms.js` … **様式ごとの欄の対応表と転記エンジン**（`KS.FORMS`, `KS.fillForm`）。node でもそのまま動く
- `sample.js` … サンプル事例（架空の人物）
- `lib/` … pdf-lib 1.17.1 / @pdf-lib/fontkit 1.1.1 / pdf.js 3.11.174（プレビュー）
- `fonts/jp.ttf` … Noto Sans JP（OFL、`fonts/OFL.txt`）を JIS 第1・第2水準にしぼったもの
  - pdf-lib の `subset: true` で使えるよう、glyf を4バイト境界にそろえてある（そろっていないと文字が欠ける）
  - 行の高さが詰まるよう ascent 880 / descent -120 にしてある（pdf-lib は 1.2×(ascent−descent) で行を送る）

## 欄の対応のしかた（forms.js）
`[PDFの欄名, 画面の名前, 値, オプション]`
- 値：キー文字列 / キーの配列（前から空でないもの）/ 関数（`uses` に使うキーを書くと画面の「反映先」バッジに出る）
- `t:'cb'` チェック、`t:'tl'` ③の1日の流れ（欄を消して時刻の位置に直接書く）、`t:'grid'` 週間表のマス
- ⑥週間計画：`sched_{mon..sun}_r01..r25`（r01＝4時、1行1時間）。⑧別紙2：`p4_c_*`（0〜3時は曜日なしの1マス）
- ⑦の元号（T・S・H）と住まいの種類は `CIRCLES` で〇を描く
- 署名欄・実習先の記入欄は `SKIP`（書かない）。「自署」欄は `printSelf` がオンのときだけ書く
- 様式ごとの上書きは `data.ov[formId][欄名]`

## 確認のしかた
node で全様式に書き込んで画像にして見る（PDFは Drive からダウンロードして使う）:
```
node -e "const KS=require('./forms.js'),D=require('./sample.js'); ..."
```
文字が多い欄は自動で小さくなり、6pt を下回ると画面に「小さくなった欄」として出る。
