# 8303

まーとん8393 — 車中泊・温泉・酒場スポットマップ（`index.html` 単一ファイルのSPA）。

## スプレッドシートへの直接書き込みを有効にする

「＋ お店を追加」パネルから入力したURL・カテゴリ・名称・メモを、Googleスプレッドシートの「spots」シートに直接追記できるようにするには、スプレッドシート側にGoogle Apps Scriptの書き込み用Webアプリを設置します。

1. 「spots」スプレッドシートを開き、メニューから「拡張機能」→「Apps Script」を選択する。
2. デフォルトの `Code.gs` の中身を、このリポジトリの `apps-script/add-spot.gs` の内容で置き換えて保存する。
3. 画面右上の「デプロイ」→「新しいデプロイ」を選択する。
4. 種類の選択で「ウェブアプリ」を選び、以下を設定する。
   - 次のユーザーとして実行: 自分
   - アクセスできるユーザー: 全員
5. 「デプロイ」をクリックし、初回はGoogleアカウントの承認を行う。
6. 発行された「ウェブアプリのURL」（`https://script.google.com/macros/s/.../exec` の形式）をコピーする。
7. アプリの「⚙ 連携設定」パネルを開き、「書き込み用Apps Script URL」欄に貼り付けて保存する。

設定後は、「お店を追加」パネルでURLとカテゴリを入力して「追加」を押すと、直接「spots」シートに1行追記されます。名称を空欄にした場合はURLのドメイン名から仮の名称が自動生成されるため、あとでスプレッドシート上で正式な名称に編集してください。

未設定の場合は従来どおり、一時的な候補リスト（ブラウザのlocalStorage）に保存されるだけの動作になります。
