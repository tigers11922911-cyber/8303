## スプレッドシートへの直接書き込みを有効にする

「＋ お店を追加」パネルから入力したURL・カテゴリ・名称・メモを、Googleスプレッドシートの「spots」シートに直接追記できるようにするには、スプレッドシート側にGoogle Apps Scriptの書き込み用Webアプリを設置します。

1. 「spots」スプレッドシートを開き、メニューから「拡張機能」→「Apps Script」を選択する。
2. デフォルトの `Code.gs` の中身を、このリポジトリの `apps-script/add-spot.gs` の内容で置き換えて保存する。
3. 画面右上の「デプロイ」→「新しいデプロイ」を選択する。
4. 種類の選択で「ウェブアプリ」を選び、以下を設定する。
   - 次のユーザーとして実行: 自分
   - アクセスできるユーザー: 全員
5. 「デプロイ」をクリックし、初回はGoogleアカウントの承認を行う。
6. 発行された「ウェブアプリのURL」（`https://script.google.com/macros/s/.../exec` の形式）をコピーする。
7. アプリの「⚙ 連携設定」パネルを開き、「書き込み用Apps Script URL」欄に貼り付けて保存する。

設定後は、「お店を追加」パネルでURLとカテゴリを入力して「追加」を押すと、直接「spots」シートに1行追記されます。名称を空欄にした場合はURLのドメイン名から仮の名称が自動生成されるため、あとでスプレッドシート上で正式な名称に編集してください。

未設定の場合は従来どおり、一時的な候補リスト（ブラウザのlocalStorage）に保存されるだけの動作になります。

# ナレジ 朗読カード（`narreji/`）

カードの見出しと本文を **Gemini の声** で朗読する、スマホ向けの学習カードアプリです（`narreji/index.html` 単一ファイル）。

📖 小学生向けの使い方マニュアル：`narreji/manual/index.html`（公開後は `https://tigers11922911-cyber.github.io/8303/narreji/manual/`。アプリ右上の「使い方」からも開けます）

- 読み始める節の選択・途中からの再開（停止した位置を覚えます）
- 段落の合間（なし〜3秒）・読む速さ（0.8〜1.6倍）
- 読み終わったら次のカードへ自動で進む／画面を閉じても朗読を継続
- 学習モード（答えを隠す・覚えた記録）
- Gemini が使えないとき（APIキー未設定・無料枠切れ・通信不良）は端末の音声で読み上げ
- 一度作った音声は端末に保存し、同じ文章は再生成しません（無料枠の節約）
- Google Apps Script 経由でスマホ・パソコン間の同期

## 使い始める

1. `narreji/` を GitHub Pages などで公開し、スマホで開きます（例：`https://<ユーザー名>.github.io/8303/narreji/`）。
   ブラウザの「ホーム画面に追加」でアプリのように使えます。
2. 「設定」→「Gemini 音声」に Gemini APIキー（`aistudio.google.com/apikey` で無料作成）を貼り付け、「保存して試し聴き」を押します。
   APIキーはその端末にだけ保存され、同期はされません。

## 同期を有効にする

1. `script.google.com` で新しいプロジェクトを作り、`apps-script/narreji-sync.gs` の内容を貼り付けます。
2. 先頭の `SYNC_KEY` を自分だけの合言葉に書き換えて保存します。
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行ユーザー「自分」、アクセスできるユーザー「全員」でデプロイします。
4. 発行されたウェブアプリのURLと合言葉を、各端末の「設定」→「同期」に入れて「今すぐ同期」を押します。

データは自分の Googleドライブの `narreji-sync.json` に保存されます。カードごとに新しく更新された方が採用され、削除も他の端末に伝わります。
